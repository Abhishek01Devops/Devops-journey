 ## What is Devops?
 Devops :  Development + Operations

 It is a practice where developers and IT operations work together to build,test,deploy and manage software faster and more reliablity using automation and monitoring.
    
## Phases of Devops :
                         Plan
                          Code
                          Build
                          Test
                          Release
                          Deplpoy
                          Operate
                          Monitor

## Linux Command practiced 
 ### pwd
         - Used to check current working directory
         - Helps avoid working in the wrong path
         - Very important before file operations

### ls
        - Lists files and folders in current directory
        - Used to verify file existence
        - Helps avoid mistakes while working in terminal

### ls -l
        - Shows file type, permissions, owner, size, and modified time
        - Used to check access rights and file details
        - Very important for scripts and server files

### ls -a
     - Shows hidden files and directories
     - Used to view important config files like .git, .env
     - Essential command for DevOps and server work

### cd
    - Used to move between directories
    - cd .. moves to parent directory
    - Very important for navigation on servers

### mkdir
    - Creates directories
    - Used to organize files and application structure

### touch
    - Creates empty files
    - Used for configs, scripts, and logs

### cat
    - Displays file content
    - Used to read configs and logs

### echo
    - Prints text or writes content into files
    - Used in shell scripts and automation

### less
    - Used to view file contents page by page
    - Helpful for reading large files like logs and config files
    - Allows scrolling, searching, and safe exit without cluttering terminal
    - Commonly used by DevOps engineers to analyze logs

### cp
    - Used to copy files or directories
    - Original file remains unchanged
    - Commonly used to create backups of config files

### mv
    - Used to move or rename files and directories
    - Can rename a file by changing its name
    - Also used to move files between folders

### rm
    - Used to delete files or directories
    - Deleted files cannot be recovered
    - Should be used carefully in servers
