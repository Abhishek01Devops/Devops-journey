
## ifconfig :
 To see network interfaces and IP details on your system.
- Check your system IP
- See which interface is active (Wi-Fi / Ethernet)
- Debug “system not connected to network”

## netstat -rn | grep default : 
To find the default gateway
- Know where traffic goes outside your system
- Confirm internet routing exists

## scutil --dns : 
To inspect DNS configuration.
- Check DNS servers
- Debug name-resolution issues
